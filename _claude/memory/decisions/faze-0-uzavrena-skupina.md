# Fáze 0 = uzavřená skupina, veřejné otevření až s klasifikátorem

**Kontext:** `CLAUDE.md` (pravidlo 8) zakazuje veřejné zobrazení kresby před automatickou
kontrolou obsahu, ale `docs/roadmap.md` řadil automatickou kontrolu až do fáze 1 —
rozsah fáze 0 měl jen „nahlášení + ruční review majitelem". Fáze 0 tedy nešla naplánovat,
aniž by porušila neporušitelné pravidlo. Nalezeno a předloženo majiteli 2026-08-18,
týž den rozhodnuto.

**Rozhodnutí:** fáze 0 běží jako **uzavřená skupina ~50 pozvaných, bez veřejné registrace**.
Žádné veřejné zobrazení neexistuje → pravidlo 8 platí triviálně. **Automatický klasifikátor
je brána k otevření hry komukoli zvenčí**, ne položka roadmapy, kterou lze přeskládat.

**Důvod:** ruční review majitelem padesát pozvaných lidí unese, otevřený internet ne.
Zároveň se tím nekupuje klasifikátor dřív, než je ověřeno, že lidé vůbec dobrovolně
kreslí — což je jediná hypotéza fáze 0.

**Důsledky:**
- Přihlášení ve fázi 0 je pozvánkou, ne otevřenou registrací.
- Přechod fáze 0 → veřejná hra má tvrdou podmínku navíc, nezávislou na kritériu
  ≥20 % návratu druhý den.
